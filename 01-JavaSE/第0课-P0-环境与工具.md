## 1. 三个必须搞懂的概念

你之前点 IDEA 的绿色三角，HelloWorld 就跑出来了。但里面到底发生了什么？

```
① 你写的源码 HelloWorld.java（人能看懂的文字）
        │   javac（编译器，JDK 自带）
        ▼
② 字节码 HelloWorld.class（JVM 能看懂的文件，人看不懂）
        │   java 命令（启动 JVM 虚拟机）
        ▼
③ 程序真的运行，屏幕上出现"你好，Java！"
```

三个名词：
- **JDK**（Java 开发工具包）：`javac`（编译器）+ `java`（运行器）+ 一堆官方工具库。你已经装好了 **Temurin JDK 17** ✅
- **JVM**（Java 虚拟机）：一台"虚拟电脑"，负责把 .class 读进来执行。**同一个 .class 文件，Windows/Mac/Linux 都能跑**——因为大家各自装了自己的 JVM。这就是 Java 号称"一次编写，处处运行"的原因，也是它称霸后端多年的核心优势。
- **.class 是中间产物**：以后你会发现一个规矩——**代码是给人看的，顺便给机器跑**。所以写代码的第一原则是"人能看懂"，命名规范、注释、缩进都为此服务。

类比：源码 = 中文菜谱；javac = 翻译官，把它翻成"厨师（JVM）"只认得的菜谱；翻译好的菜谱谁家的厨师都能照着做（跨平台）。

## 3. 任务 1（3 分钟）：把 HelloWorld 逐词读明白

打开 `MyFirstProject/src/HelloWorld.java`，对照注释理解每一行：

```java
public class HelloWorld {                    // 类名必须和文件名一致（HelloWorld.java）
    public static void main(String[] args) { // main 是程序入口，这行是"固定咒语"，先背下来
        System.out.println("你好，Java！");  // System.out = 屏幕，println = 打印一行并换行
    }
}
```

**固定咒语**（以后每个程序的起点都长这样，背到肌肉记忆）：
```java
public class Xxx {
    public static void main(String[] args) {
        // 你的代码写在这里
    }
}
```

## 5. 任务 3（15 分钟）：绕开 IDEA，亲手用命令编译运行一次

IDEA 只是帮你自动执行了 javac/java，我们要亲手做一次，原理才记得牢：

1. 在 IDEA 里打开底部 **Terminal** 标签（或 Windows 资源管理器地址栏输入 `cmd` 回车）
2. 一条条执行（在 `MyFirstProject` 目录下）：
```
javac -encoding UTF-8 -d out src/HelloWorld.java
java -cp out HelloWorld
```
3. 看到和你点绿三角一样的输出 = 成功。
4. 打开 `MyFirstProject/out` 目录，找到 `HelloWorld.class` —— 亲手摸一摸字节码文件。

> 两个小知识：`-encoding UTF-8` 告诉编译器源码是 UTF-8 编码（否则中文注释可能乱码报错）；`-cp` 是 classpath，告诉 java 去哪里找 .class。**如果运行后中文在终端里显示成乱码**（如 `��ã�Java`）——这是 Windows 控制台编码问题，不是代码问题。两个办法：① 敲 `chcp 65001` 回车后，用 `java -Dfile.encoding=UTF-8 -cp out HelloWorld` 运行；② 图省事就直接以 IDEA 运行窗口（绿三角）的结果为准，命令行只求看到"编译运行流程"。别在乱码上耗时间。

## 6. 任务 4（20 分钟）：让程序"听得懂人话"——Scanner 输入

把 HelloWorld.java 改成下面这样（这段代码里有两个新东西：`import` 和 `Scanner`）：

```java
import java.util.Scanner;                    // ① 引入工具：Scanner 负责读键盘输入

public class HelloWorld {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in); // ② 造一个"键盘读卡器"（System.in = 键盘）
        System.out.print("请输入你的名字："); // ③ print 不换行，光标停在冒号后
        String name = sc.nextLine();         // ④ 读入一整行文字，存进 name 变量
        System.out.println("你好，" + name + "！欢迎开始学 Java！");
        sc.close();                          // ⑤ 用完关掉，好习惯
    }
}
```

运行，输入你的名字回车，看它怎么回应你。

**自己加一个功能**：再多问一个"你多大了？"，回答"我 X 岁了，还要学 X 年 Java"。（提示：`nextLine()` 读到的都是文字，数字可以先用 `String age = sc.nextLine();` 接住，拼接打印即可——"类型转换"是下一课的事，别贪多。）

## 7. 任务 5（20 分钟）：调试初体验——看程序"一步一步走"

Debug 是程序员最重要的技能之一，现在就用 5 步学会它：
1. 在任务 4 代码的 `String name = sc.nextLine();` 这一行**左侧灰色边栏点一下** → 出现红点 = 断点
2. 点右上角**绿色甲虫图标**（或 Shift+F9）以 Debug 模式运行
3. 程序会在红点处**暂停**，这一行还没执行
4. 按 **F8（Step Over）** 一步一步走，看下方 Variables 面板里 `name` 变量从无到有
5. 按 **F9（Resume）** 让程序一口气跑完；最后把那行左边的红点再点一下取消断点

> 直觉：断点 = 给程序贴一张"到此暂停"的便利贴，方便你偷看它每一步手里拿着什么数据。以后查 bug 全靠它。

## 8. 任务 6（30 分钟）：建 GitHub 仓库，把代码推上去

Git = 代码的"存档系统 + 时光机"；GitHub = 把存档放到云上。**从今天起，每天写的代码都要推上去**（它是你的"作品集"，也是面试官看的证据）。

1. 没有账号先去 [github.com](https://github.com) 注册（用户名记下来，以后简历要放）
2. 回到 IDEA 的 Terminal，**在 `C:\Users\38875\Desktop\Java学习` 根目录**执行（首次用 Git 先自我介绍一次）：
```
git config --global user.name "你的GitHub用户名"
git config --global user.email "你注册的邮箱"
git init
git add .
git status
```
3. 检查 `git status` 的列表：**绿色 = 会被提交**。确认 `.idea/`、`*.iml`、`out/`、`*.lnk` 这些垃圾文件**不在**列表里（我在仓库根目录已放好 `.gitignore`，它会自动过滤）
4. 提交第一个版本：
```
git commit -m "第0课：环境就绪，HelloWorld 与学习规划"
```
5. 浏览器打开 github.com → New repository → 名字填 `JavaLearning` → 不要勾任何选项 → Create
6. 复制页面给出的仓库地址（形如 `https://github.com/你的用户名/JavaLearning.git`），回 Terminal：
```
git remote add origin 你的仓库地址
git branch -M main
git push -u origin main
```
7. 刷新 GitHub 页面，看到文件都上去了 = 成功 🎉

> 可能遇到的坑：如果 push 时提示要密码——GitHub 从 2021 年起**不再支持账号密码**，需要令牌：GitHub 头像 → Settings → Developer settings → Personal access tokens → Generate new token（勾选 `repo` 权限）→ 复制以 `ghp_` 开头的一串 → 在密码框粘贴它。嫌麻烦也可以改用 GitHub Desktop 客户端（可视化，之后我再带你）。

## 11. 报错阅读三步法（以后每次报错都这么干）

1. **读第一行**：它告诉你"哪个文件的第几行"出了问题（IDEA 里可直接点击跳转）
2. **读最后一个词**：通常是错误类型，如 `cannot find symbol`（名字写错了）、`';' expected`（少分号）、`incompatible types`（类型不匹配）
3. **自己修 5 分钟**，修不好 → 把**完整报错 + 代码**发给我
