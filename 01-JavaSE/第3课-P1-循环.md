## 1. 为什么要循环？

```java
System.out.println("第1天背了20个单词");
System.out.println("第2天背了20个单词");
System.out.println("第3天背了20个单词");
// ...要写 100 行？离谱。
```
循环就是告诉电脑：**"这句话重复做 N 次"**。人怕重复，机器最爱重复——这是程序员的浪漫。

## 2. 三种循环

### 2.1 for —— "我知道要循环几次"时用（最常用）

```java
// 打印 1~5
for (int i = 1; i <= 5; i++) {
    System.out.println(i);
}
```

**for 的执行顺序（必背，面试常问）**：
```
for (①初始化; ②条件判断; ④步进更新) {
    ③循环体
}
执行顺序：① → ②(true) → ③ → ④ → ②(true) → ③ → ④ → ... → ②(false) 退出
```
写个断点在循环里 F8 一步步走，亲眼确认这个顺序（本课必做实验）。

三个细节：
- `int i = 1` 声明在 for 的"头"里 → i **只在这个循环内有效**，循环结束就消失
- 循环条件只要**少写一个 =** 就是经典 bug：`i <= 5` 写了 `i < 5` → 少一次；反过来的死循环见 §4
- `i++` 不一定是 +1，`i += 2` 可以跳着走（打印奇数）

### 2.2 while —— "不知道几次，只看条件"时用

```java
// 经典场景：反复输入，直到输入 -1 为止（-1 叫"哨兵值"）
Scanner sc = new Scanner(System.in);
System.out.print("输入成绩（-1 结束）：");
int score = sc.nextInt();
while (score != -1) {
    System.out.println("收到：" + score);
    System.out.print("输入成绩（-1 结束）：");
    score = sc.nextInt();        // ⚠️ 忘了这行 = 死循环！
}
```

### 2.3 do-while —— "至少执行一次"时用

```java
int n;
do {
    System.out.print("请输入一个正数：");
    n = sc.nextInt();
} while (n <= 0);       // 不满足就再来一遍
```
和 while 的唯一区别：**先做一次再判断**。常用于"必须至少输入一次"的校验。

### 什么时候用哪个？（面试会问）

| 场景 | 选择 |
|---|---|
| 知道确切次数（打印 1~100） | for |
| 次数不确定，靠条件结束（读到 -1 为止） | while |
| 至少要执行一次（输入校验） | do-while |

## 3. break / continue（循环的两个"控制键"）

```java
for (int i = 1; i <= 10; i++) {
    if (i == 5) {
        break;        // 立刻跳出整个循环 → 只打印 1~4
    }
    System.out.println(i);
}

for (int i = 1; i <= 10; i++) {
    if (i % 2 == 0) {
        continue;     // 跳过本次，直接进下一次 → 只打印奇数 1 3 5 7 9
    }
    System.out.println(i);
}
```
口诀：**break 是"全剧终"，continue 是"这一集跳过"**。

## 4. 死循环（新手第一杀手，必看）

```java
int i = 1;
while (i <= 10) {
    System.out.println(i);
    // 忘了 i++ → i 永远是 1 → 条件永远成立 → 程序永远不停！
}
```
**如果不小心跑出了死循环**（控制台疯狂刷屏）：点控制台左上角的**红色方块 ■ 停止按钮**，程序就停了。每个新手都该经历一次死循环 + 一次红色方块，经历完你就长记性了。

怎么防？
1. while 循环体里**必有改变条件的语句**
2. 不确定时先用小数字测试（`i <= 10` 先跑通再改 1000000）

## 5. 循环四板斧（算法题全靠它）

几乎所有基础题都是这几个模式的组合，看到题先想属于哪种：
1. **计数**：`int count = 0; ... count++;`
2. **累加**：`int sum = 0; sum += x;`
3. **打擂台（找最大/最小）**：`int max = 最小值; if (x > max) max = x;`
4. **拼接**：`String s = ""; s += x + ",";`（小数据量可用，大数据量用 StringBuilder——以后学）

```java
// 经典"打擂台"：输入 5 个数，打印最大值
Scanner sc = new Scanner(System.in);
int max = -1;              // 擂主先设个很小的值
for (int i = 1; i <= 5; i++) {
    System.out.print("第" + i + "个数：");
    int x = sc.nextInt();
    if (x > max) {
        max = x;           // 来者更强，换擂主
    }
}
System.out.println("最大的是：" + max);
```

## 6. 嵌套循环（打印图形的基础）

```java
// 打印 3 行 5 列的 *
for (int row = 1; row <= 3; row++) {      // 外层管行
    for (int col = 1; col <= 5; col++) {  // 内层管列
        System.out.print("*");            // print：不换行
    }
    System.out.println();                 // 一行结束，换行
}
```
调试嵌套循环时，在**内层**打断点，观察 row 和 col 怎么变——row 变一次，col 要跑满一轮。

## 参考答案（写完 E5 再往下看）

1. ①初始化 → ②判断（true 才继续）→ ③循环体 → ④步进 → 回到②……②为 false 退出。
2. 执行 4 次（i=1,2,3,4）。循环结束后 i 已经**不存在**了（for 头里声明的变量出循环即失效，打印会编译报错）。
3. do-while 先执行一次循环体再判断条件，至少执行一次；while 先判断，可能一次都不执行。
4. `for (int i = 1; i <= 100; i += 2)`。
5. break 跳出整个循环；continue 跳过本次继续下一次。
6. 1+2+4+5+7+8+10 = **37**（3、6、9 被 continue 跳过）。
7. 循环条件永远为 true（如忘了写步进）。按控制台左上角红色方块 ■。
8. 擂主设小值，保证第一个输入就能"打败"它登台。若设 0 且输入全为负，max 会错误地保持 0——所以更稳的写法是把擂主设为第一个输入的值（或 int 最小值）。
9. 9 行（外层 3 次 × 内层 3 次，println 每次都换行）。
10. 参考：
