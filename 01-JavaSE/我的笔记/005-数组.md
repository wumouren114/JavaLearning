## 一、验收问答（学员答案 + 订正）

**1. `int[] a = new int[4];` 的合法编号？`a.length` 是几？**

学员：`0123`、`4` ✅ 满分
（编号从 0 开始：0、1、2、3；括号里的 4 是"数量"）

**2. 想访问数组的最后一个元素，用 `length` 怎么写？**

学员：`length - 1` 🟡 说对了一半（这是"最后一个的编号"）
→ **完整写法：`a[a.length - 1]`**（方括号里可以直接写算式，Java 先算 `a.length - 1` 再当下标用）

**3. 数组的"存"和"取"分别怎么写？**

学员：存 = `int[] = {}`（❌ 那是"创建数组"，不是存元素）；取 = 不会
→ **订正（区分两个层级）**：

| 层级 | 动作 | 写法 |
|---|---|---|
| 数组级 | 创建/声明 | `int[] a = new int[4];`　`int[] a = {90, 85, 92};` |
| 元素级 | **存**（写入某格） | `a[0] = 90;`　`a[i] = Integer.parseInt(sc.nextLine());` |
| 元素级 | **取**（读出某格） | `int x = a[0];`　`System.out.println(a[i]);`　`sum += a[i];` |

→ 一句话：**存 = 下标在等号左边；取 = 下标在等号右边被使用**。

**4. 遍历数组为什么写 `i < arr.length` 而不是 `i <= arr.length`？**

学员：复习后理解 ✅
→ 最大合法编号是 `length - 1`；写 `<=` 会让 i 走到 `length`，访问不存在的柜子 → 抛 `ArrayIndexOutOfBoundsException`。
**学员亲手踩过**：`SortDemo` 里写 `i <= scores.length`，程序崩在 `scores[5]`，报 `Index 5 out of bounds for length 5`。

**5. 增强 for 能给数组元素赋值吗？**

不能。`for (int s : scores) { s = s + 5; }` 改的是**每格值的副本**，原数组不变。
要改必须用普通 for + 下标：`scores[i] = scores[i] + 5;`
**学员做过对比实验**（先增强 for 版本没变化，再普通 for 版本才真的 +5）。

**6. 二维数组里 `scores.length` 与 `scores[row].length` 分别是什么？**

- `scores.length` = **行数**（几行）
- `scores[row].length` = **第 row 行的列数**（这一行有几格）

**7. 想一次打印整个数组、想排序，分别用什么？**

- 打印：`Arrays.toString(a)`；**二维**要用 `Arrays.deepToString(a)`（普通 toString 会打印地址乱码）
- 排序：`Arrays.sort(a)`（从小到大，**原地**修改原数组）
- 都要先 `import java.util.Arrays;`

## 四、代码归档

### 1）ArrayDemo：录入 5 个成绩 → 遍历打印 → 总分/平均分

```java
import java.util.Scanner;

public class ArrayDemo {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int[] scores = new int[5];
        int sum = 0;

        for (int i = 0; i < scores.length; i++) {          // 录入（存）
            System.out.print("请输入第" + (i + 1) + "次成绩：");
            scores[i] = Integer.parseInt(sc.nextLine());
            sum += scores[i];                              // 顺便累加（取）
        }
        System.out.println("这5次成绩为：");
        for (int s : scores) {                             // 遍历打印（增强 for，只读）
            System.out.print(s + "  ");
        }
        System.out.println();
        System.out.println("总分：" + sum);
        System.out.println("平均分：" + (double) sum / scores.length);
        sc.close();
    }
}
```

### 2）SortDemo：Arrays 工具、排序、最值、倒序、引用陷阱

```java
import java.util.Arrays;

public class SortDemo {
    public static void main(String[] args) {
        int[] scores = {88, 92, 70, 95, 81};

        System.out.println(Arrays.toString(scores));    // 打印原数组
        Arrays.sort(scores);                            // 排序（原地）
        System.out.println(Arrays.toString(scores));

        System.out.println("最低分：" + scores[0]);
        System.out.println("最高分：" + scores[scores.length - 1]);

        System.out.print("倒序：");
        for (int i = scores.length - 1; i >= 0; i--) {
            System.out.print(scores[i] + "  ");
        }
        System.out.println();

        int[] copy2 = Arrays.copyOf(scores, scores.length);   // 真复制
        copy2[0] = 0;
        System.out.println(Arrays.toString(scores));          // 原数组不变

        for (int i = 0; i < scores.length; i++) {             // 只有普通 for 能改元素
            scores[i] = scores[i] + 5;
        }
        System.out.println(Arrays.toString(scores));
    }
}
```

### 3）MatrixDemo：二维数组、双层循环、每行总分、全班平均分、最高分位置

```java
import java.util.Arrays;

public class MatrixDemo {
    public static void main(String[] args) {
        int[][] scores = {
            {90, 85, 92},
            {78, 88, 80},
            {95, 92, 98}
        };
        int total = 0;

        System.out.println(Arrays.deepToString(scores));

        for (int row = 0; row < scores.length; row++) {              // 打印表格
            for (int col = 0; col < scores[row].length; col++) {
                System.out.print(scores[row][col] + "\t");
            }
            System.out.println();
        }

        for (int row = 0; row < scores.length; row++) {              // 每人总分
            int sum = 0;
            for (int col = 0; col < scores[row].length; col++) {
                sum += scores[row][col];
            }
            System.out.println("第" + (row + 1) + "个学生总分：" + sum);
            total += sum;
        }
        System.out.println();
        System.out.println("班级平均分：" + (double) total / (scores.length * scores[0].length));

        int max = scores[0][0];                                     // 打擂台找最高分
        int maxRow = 0;
        int maxCol = 0;
        for (int row = 0; row < scores.length; row++) {
            for (int col = 0; col < scores[row].length; col++) {
                if (scores[row][col] > max) {
                    max = scores[row][col];
                    maxRow = row;
                    maxCol = col;
                }
            }
        }
        System.out.println("最高分：" + max + "，在第 " + (maxRow + 1) + " 行第 " + (maxCol + 1) + " 列");
    }
}
```
