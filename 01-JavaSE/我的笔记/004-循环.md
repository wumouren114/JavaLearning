## 一、核心概念（自己的话解释）

1. for 循环的执行顺序是什么？（用 ①②③④ 标出来）

   **学员答案**：初始值 → 条件值 → 步进值 → 循环（🟡 顺序需订正）
   **正确顺序**：①初始化（**只做一次**）→ ②条件判断 → ③**循环体** → ④步进 → **回到②**……条件为假时退出。
   【批注】步进（i++）发生在**循环体之后**，不是之前；而且每一轮都要"回到②"再判断一次。

2. for / while / do-while 分别用在什么场景？各配一个例子。

   **学员答案** ✅：for 用于**知道循环次数**的场景；while 用于**不知道要循环多少次**的场景；do-while 先跑一遍再判断；while 与 for 可以互相改写。
   **例子**：for → 打印 1~100；while → 一直输入直到输入 -1；do-while → 猜数字（至少猜一次）。
   **补充**：do-while 天生适合"**至少做一次**"（输入校验、菜单、猜数字）。

3. break 和 continue 的区别？

   **学员答案** ✅：break 是**结束整个循环**（猜数字 7 次机会用完时用它让游戏失败）；continue 是**跳过本轮**（列偶数时遇到奇数就跳过）。
   学员例子：
   ```java
   for (int i = 1; i <= 10; i++) {
       if (i % 2 != 0) {
           continue;      // 跳过奇数 → 只打印偶数
       }
       System.out.println(i);
   }
   ```
   【提醒】代码里的 `!=` 必须是**半角**；用中文全角的 `！` 会报"非法字符"。

4. 我是怎么理解"打擂台"找最大值的思路的？

   **课上没印象 → 课后补讲并已动手实现**：
   思路：**第 1 个数当擂主**，后面每个数依次挑战：`if (x > max) { max = x; }`，全部挑战完台上的就是最大。
   **坑**：擂主初值若写成 `int max = 0;`，当输入全是负数时会**错误地输出 0** → 用第一个数当擂主最稳。
   已实测：`4 7 8 4 6` → 8 ✅

## 四、我今天写的代码

### 1）猜数字游戏（7 次机会 + 胜负判断）

```java
import java.util.Scanner;

public class GuessNum {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        int answer = (int) (Math.random() * 100) + 1;   // 1~100 的答案
        int count = 0;                                   // 计数器
        int guess = 0;

        do {
            System.out.print("输入一个数字（共 7 次机会）：");
            guess = Integer.parseInt(sc.nextLine());
            count++;

            if (guess > answer) {
                System.out.println("大了");
            } else if (guess < answer) {
                System.out.println("小了");
            } else {
                System.out.println("猜中了");
            }
        } while (guess != answer && count < 7);           // 没猜中且还有机会

        if (guess == answer) {                            // 事后判断"为什么退出"
            System.out.println("恭喜，你用了" + count + "次猜中！");
        } else {
            System.out.println("挑战失败，正确答案是 " + answer);
        }

        sc.close();
    }
}
```

```java
public class Table99 {
    public static void main(String[] args) {
        for (int row = 1; row <= 9; row++) {
            for (int col = 1; col <= row; col++) {        // col <= row 才有三角形
                System.out.print(col + "×" + row + "=" + col * row + "\t");
            }
            System.out.println();                          // 一行结束换行
        }
    }
}
```

### 3）打擂台找最大值

```java
import java.util.Scanner;

public class MaxFinder {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        System.out.print("请输入第 1 个数：");
        int max = sc.nextInt();                            // 第一个数当擂主

        for (int i = 2; i <= 5; i++) {
            System.out.print("请输入第 " + i + " 个数：");
            int x = sc.nextInt();
            if (x > max) {
                max = x;                                   // 挑战成功，换擂主
            }
        }

        System.out.println("最大值是：" + max);
        sc.close();
    }
}
```
