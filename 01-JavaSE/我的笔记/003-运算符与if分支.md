## 一、核心概念（自己的话解释）

1. `a++` 和 `++a` 的区别？（配一个例子）

   **学员答案**：a++ 是先把值交出去、再加一；++a 则相反（先加，再交值）。

   例子（**已订正**）：
   ```java
   int a = 4;
   int b = a++;    // b 拿到的是"加之前"的旧值 4；然后 a 自己 +1 变成 5
   int c = ++a;    // a 先 +1 变成 6；c 拿到新值 6
   // 最终：a = 6，b = 4，c = 6
   ```
   【批注】原答案里写 `b=5` 是错的——后缀"先用后加"，交出去的必须是加之前的 4。
   口诀：**前加后用，后加先用**（`++` 不管前后，a 都会 +1，区别只在"交出去的值是新的还是旧的"）。

2. 什么是"逻辑短路"？`&&` 和 `||` 分别在什么情况下会短路？

   **学员原答**（❌ 需订正）：~~&& 时一个不满足一个满足会触发，|| 时均不满足会触发~~

   **正确答案**：
   - `A && B`：当 **A 为假** 时，B **根本不执行**（因为结果必然是假）
   - `A || B`：当 **A 为真** 时，B **根本不执行**（因为结果必然是真）
   - 口诀：**`&&` 见假就停，`||` 见真就停**
   - 用处：`if (count > 0 && total / count > 10)` —— 先用 `count > 0` 挡掉除零，再看后面

3. if-else if 链的执行规则是什么？为什么 else if 里不用再写"并且小于上一个条件"？

   **学员答案**：先看 if，不满足才走 else if；因为能走到 else if，就已经默认上一个条件不满足了。✅
   补充：命中一个分支就**退出整条链**，所以"≥80"那档天然只可能是 80~89。

4. 判断 String 内容相等为什么不能用 `==`？

   **学员原答**（🟡 需精确）：~~== 是比数字的……~~
   **准确说法**：`==` 比的是"**是不是同一个柜子（内存地址）**"。数字变量的盒子里装的就是值本身，所以 `==` 能用；String 变量盒子里装的是"地址编号"，所以要 `.equals()` 进屋比内容。
   一句话：**`==` 认编号，`equals` 认内容**。
   （唯一必须用 `==` 的 String 场景：判空 `name == null`——因为 null 没有柜子，用 equals 会直接崩。）

## 四、我今天写的代码（闰年判断最终版）

```java
import java.util.Scanner;

public class Leapyear {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.print("请输入年份：");
        int year = sc.nextInt();

        boolean div400 = (year % 400 == 0);
        boolean div4 = (year % 4 == 0);
        boolean not100 = (year % 100 != 0);

        boolean leap = div400 || (div4 && not100);

        if (leap) {
            System.out.println(year + "是闰年");
        } else {
            System.out.println(year + "是平年");
        }
        sc.close();
    }
}
```
