## 1. 运算符总览（先混个脸熟，用熟 80% 就够了）

| 类别 | 运算符 | 说明 |
|---|---|---|
| 算术 | `+ - * / %` | % = 取余数（判断奇偶、拆数字全靠它） |
| 自增自减 | `++ --` | 让变量 +1/-1，有前后缀之分（见 2） |
| 赋值 | `= += -= *= /= %=` | `a += 5` 就是 `a = a + 5` |
| 比较 | `== != > < >= <=` | 结果一定是 boolean（true/false） |
| 逻辑 | `&& ｜｜ !` | 与（且）、或、非 |
| 三元 | `条件 ? A : B` | 条件成立取 A，否则取 B |
| 字符串 | `+` | 拼接文字：`"年龄" + age` |

**优先级不背表**，记住一句话：**先算术、再比较、后逻辑，赋值最低；拿不准就加括号**。比如：

```java
boolean ok = (score >= 60) && (score <= 100);
int max = (a > b) ? a : b;          // 三元：a>b 就取 a，否则取 b
```

## 2. `++` 的前缀 vs 后缀（面试高频小陷阱）

```java
int a = 5;
int b = a++;      // 后缀：先取 a 的当前值给 b，a 再自增 → b=5, a=6
int c = ++a;      // 前缀：a 先自增，再把新值给 c → a=7, c=7
```
口诀：**"前加后用，后加先用"**。单独一行写 `a++;` 时两者没区别。

## 3. 比较与逻辑的几个坑（提前排雷）

1. **`==` 比的是"值"**：基本类型直接用 `==` 没问题。但**字符串（String）必须用 `.equals()`**：
   ```java
   String s1 = "abc";
   String s2 = "abc";
   s1 == s2            // 结果可能是 true 也可能 false（涉及内存地址，别赌）
   s1.equals(s2)       // ✅ 这才是判断"内容一样吗"的正确姿势
   ```
2. **别用 `==` 比较小数**：`0.1 + 0.2 == 0.3` 是 **false**（浮点数二进制存储天生有误差）。需要精确比较小数，以后学 BigDecimal；现在知道这个坑即可。
3. **逻辑短路**：`a && b` 如果 a 已经是 false，b **根本不会执行**；`a || b` 如果 a 是 true，b 也不执行。经典例子：
   ```java
   int x = 10;
   boolean r = (x > 100) && (x++ > 0);   // x>100 为 false，后面 x++ 不执行！
   System.out.println(x);                // 还是 10，不是 11
   ```
4. **`!` 非运算**：`!(age >= 18)` 等于 `age < 18`。用 ! 别叠太多，两层以上就绕晕了。

## 4. if 分支：程序开始"思考"

```java
int score = 85;
if (score >= 60) {                       // 条件成立 → 进这个块
    System.out.println("及格");
} else {                                 // 不成立 → 进这里（可省略）
    System.out.println("不及格");
}
```

**多分支用 else if 串起来**：
```java
if (score >= 90) {
    System.out.println("优秀");
} else if (score >= 80) {
    System.out.println("良好");
} else if (score >= 60) {
    System.out.println("及格");
} else {
    System.out.println("不及格");
}
```
注意执行规则：**从上往下，命中一个就退出整条链**——所以 `score >= 80` 不用写成 `score >= 80 && score < 90`。

**三个铁律**：
1. `if` 的条件**必须是 boolean**：`if (age = 18)` 是编译错误（`=` 是赋值），新手写错 `if (age == 18)` 一抓一个准。
2. **永远写花括号**（哪怕只有一行）——少写 `{}` 是新手被坑率最高的习惯之一：
   ```java
   if (a > b)
       System.out.println("a大");
       System.out.println("猜猜这行什么时候执行？");   // ❌ 这行不属于 if！
   ```
3. 先判"正常情况"还是先判"边界"？养成习惯先处理**最简单/最常见**，再处理特殊情况。

**boolean 变量做开关**（好习惯）：
```java
boolean isAdult = age >= 18;
if (isAdult) { ... }
```

## 5. switch：多个"等于"的判断

适合"一个值等于几种情况"的场景（JDK 14+ 的新写法，不用写 break，清爽）：

```java
int day = 3;
String week = switch (day) {
    case 1 -> "周一";
    case 2 -> "周二";
    case 3 -> "周三";
    default -> "其他";       // default 兜底，别忘
};
System.out.println(week);
```
老代码（`case 1: ... break;`）也要能看懂——网上教程和公司老项目里都是那种写法。switch 能判断的类型：int、char、String、枚举（后面学）。

## 6. 本课练习（lesson02 包）

- **E1 成绩等级**：输入 0~100 的成绩，输出 优秀/良好/及格/不及格（先处理非法输入：`if (score < 0 || score > 100)` 提示"成绩不合法"）。
- **E2 闰年判断**：输入年份，输出"是闰年/不是闰年"。闰年规则：能被 400 整除，或（能被 4 整除且不能被 100 整除）：
  ```java
  boolean leap = (year % 400 == 0) || (year % 4 == 0 && year % 100 != 0);
  ```
- **E3 三数比大小**：输入三个数，输出最大值和最小值（先自己想，至少写出两种解法）。
- **E4 简单计算器 v1**：输入 两个数 + 一个运算符号（+ - * /），用 switch 计算结果。除法要处理 `除数不能为 0`。
- **E5 挑战（选做）**：判断一个三位数是不是"水仙花数"（153 = 1³ + 5³ + 3³）。提示拆位：`int a = n / 100; int b = n / 10 % 10; int c = n % 10;`，比较 `a*a*a + b*b*b + c*c*c == n`。

## 参考答案（写完 E5 再往下看）

1. a=4，b=3（后缀：b 先拿到 3，a 再变 4）。
2. **会报错**（运行时抛 ArithmeticException: / by zero）。因为 `&&` 左边 `3>2` 是 true，所以右边的 `5/0` **会被执行**，除零直接炸。反过来，如果左边是 false，右边才会被短路跳过——记住：**短路只在"左边结果已定"时生效**，救不了除零。
3. 不合法：`=` 是赋值不是比较，if 需要 boolean，编译报错（应该是 `==`）。
4. `s1.equals(s2)`。`==` 比的是引用地址，equals 才比内容。
5. false（浮点数精度问题）。
6. x = 11（10+3=13，13-2=11）。
7. 7%3=1；-7%3 在 Java 里是 **-1**（符号跟被除数走）。知道这点以后做题不懵。
8. 20。
9. 防止"下一行不属于 if"的经典 bug；代码可读性也更好。
10. r=true；b>0 **不会**再判断（`||` 左边 true 短路）。
