## 1. 新概念：变量 = 带名字的盒子

电脑的内存（RAM）可以想象成**一排排整齐的小格子**，每个格子都能存一个数。问题是：格子太多（几十亿个），你怎么记得住哪个格子里存的是什么？

**变量（variable）= 你亲手贴了名字标签的一个格子。**
- 往格子里放东西，叫**赋值**（`=`）
- 格子里东西可以换，所以叫"变"量
- 你只跟名字打交道（"把 age 打印出来"），不用管它在内存哪个地址

先建一个练习项目（只建一次，以后所有课都用它）：
> IDEA → File → New → Project → Name 填 `JavaSE练习` → Location 选 `C:\Users\38875\Desktop\Java学习\01-JavaSE` → 选 JDK 17 → Create
> 然后在 `src` 上右键 → New → Package → 输入 `lesson01` → 在 lesson01 里右键 → New → Java Class → 输入 `Demo1`

```java
package lesson01;

public class Demo1 {
    public static void main(String[] args) {
        // 1. 声明：造一个盒子（类型 + 名字）
        int age;
        // 2. 赋值：往盒子里放东西
        age = 18;
        // 3. 使用：拿出来看
        System.out.println(age);

        age = 19;              // 4. 换内容：同一个盒子，新值盖旧值
        System.out.println(age);

        int score = 95;        // 5. 声明 + 赋值一步到位（最常用写法）
        System.out.println("这次考了" + score + "分");   // 字符串拼接：+ 能把文字和数据接起来
    }
}
```

**三个必须记住的规矩**：
1. **变量必须先赋值，才能使用**。把上面 `age = 18;` 删掉再运行，你会看到报错 `variable age might not have been initialized`——试一次，记住这个报错的样子。
2. 变量只能在**声明它的那对大括号内**使用（作用域，现在先感受，后面细讲）。
3. 同一个大括号里，**不能声明两个同名变量**。

## 2. 为什么必须分"类型"？

不同类型的数据占的内存大小不同、能干的事不同：
- 年龄 18 用 4 个字节的 `int` 就行；存 30 亿就需要 `long`（8 字节）
- 文字和数字不能混着运算

Java 是**强类型语言**：每个盒子在造出来时就固定了形状，放错类型的东西会直接报错（这其实是在帮你早发现错误）。

## 3. 基本类型全家福（8 种，先记 5 种）

| 类型 | 中文名 | 占空间 | 能存什么 | 例子 |
|---|---|---|---|---|
| `int` | 整型 | 4 字节 | 整数 ±21 亿内 | `int age = 18;` |
| `long` | 长整型 | 8 字节 | 更大的整数 | `long money = 3000000000L;`（末尾 **L** 别丢） |
| `double` | 双精度浮点 | 8 字节 | 小数 | `double pi = 3.14;` |
| `boolean` | 布尔 | 1 字节 | 只有 true/false | `boolean ok = true;` |
| `char` | 字符 | 2 字节 | 一个字符（单引号） | `char c = 'A'; char c2 = '中';` |
| `byte` / `short` / `float` | — | — | 用得少，**先跳过**，用到再学 | — |

补充两点：
- `float` 很少用（精度低又难记 `3.14F` 的后缀），面试知道有它即可
- `String`（字符串）其实是**引用类型**，但现在你就当它是"装文字的特殊盒子"用，双引号：
  ```java
  String name = "小明";
  ```

**为什么 int 上限是约 21 亿？** 4 字节 = 32 位，最高位是符号位，剩下 31 位能表示 2^31 种状态 ≈ 21.47 亿。现在知道概念即可，二进制后面会学。

## 4. 变量命名规范（面试官会看你的代码习惯）

**必须遵守**：
- 只能由字母、数字、`_`、`$` 组成，**不能数字开头**（`1age` 非法）
- 不能用**关键字**（`class`、`int`、`public` 这些词被 Java 占用了）
- 见名知意：`studentName` 好，`s`、`abc`、`x1` 差
- **小驼峰**：第一个单词小写，后面单词首字母大写 → `myScore`、`totalMoney`
- 坚持用**英文命名**，别用拼音（`xueshengMingzi` 会被同事嫌弃）

```java
int studentAge = 18;      // ✅ 好
int a = 18;               // ⚠️ 差：a 是什么？
int nianLing = 18;        // ❌ 拼音
int 2phone = 18;          // ❌ 数字开头
int class = 18;           // ❌ class 是关键字
```

## 5. 常量与注释

- **常量**：值永远不变的变量，用 `final` 修饰，名字**全大写 + 下划线**：
  ```java
  final double PI = 3.14159;
  final int MAX_SCORE = 100;
  ```
  以后写"魔数"（代码里凭空冒出来的数字）是好习惯的大敌，常量就是解药。
- **三种注释**：
  ```java
  // 单行注释
  /* 多行
     注释 */
  /** 文档注释：写给使用者看的说明（鼠标悬停会出现） */
  ```

## 6. 类型转换：三个新手坟场（重点中的重点）

### 6.1 自动转换（小盒子 → 大盒子，安全）
```java
int a = 10;
long b = a;        // ✅ int 装进 long，自动
double c = b;      // ✅ 整数变小数，自动
```

### 6.2 坟场一：整数除法会"截断"
```java
System.out.println(5 / 2);     // 输出 2，不是 2.5！
System.out.println(10 / 3);    // 输出 3
```
两个整数相除，结果**还是整数**（小数部分直接扔掉，不是四舍五入）。想得到小数，至少一边写成小数：`5 / 2.0` 或 `5.0 / 2` 或 `(double) 5 / 2`。
> 新手必踩：摄氏转华氏 `F = C * 9 / 5 + 32` 写着写着就变 `C * 1 + 32` 了。今天练习 E2 就是让你踩这个坑。

### 6.3 坟场二：字面量的默认类型
```java
long x = 3000000000L;   // 不写 L 会报错：3000000000 默认按 int 算，超范围了
float f = 3.14F;        // 不写 F 会报错：小数默认是 double，double 不能自动缩成 float
```

### 6.4 坟场三：强制转换会"截断 + 丢精度"
```java
double d = 3.99;
int n = (int) d;      // 得 3！直接砍掉小数部分，不是四舍五入
int m = (int) 3.7;    // 得 3
```
还有溢出问题：`int` 存不下时数值会"绕回"成负数（有兴趣可以试试 `int x = 2147483647; x = x + 1;` 输出什么——这就是溢出）。

## 7. Scanner 读数字 + 一个经典大坑

```java
import java.util.Scanner;

public class Demo2 {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.print("请输入年龄：");
        int age = sc.nextInt();          // 读一个整数
        System.out.println("十年后你" + (age + 10) + "岁");
        sc.close();
    }
}
```

**经典坑（今天就要记住）**：`nextInt()` 只吃掉数字，**把回车键留在缓冲区**。如果你紧接着用 `nextLine()` 读名字，会读到"空字符串"：
```java
int age = sc.nextInt();
String name = sc.nextLine();   // ❌ 读到的是一行空的！
```
**两种解法**：
1. 数字全用 `nextInt()`，中间别混 `nextLine()`；文字用 `sc.nextLine()` 读完整行后自己转：`int age = Integer.parseInt(sc.nextLine());`
2. 或者每次 `nextInt()` 后补一个 `sc.nextLine();` 把回车吃掉

今天统一用解法 1 的思路：**读一行 → 自己转**，最不容易出错。
