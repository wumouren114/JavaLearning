## 一、程序是怎么跑起来的（P0）

```
HelloWorld.java（人写的源码）
     │  javac 编译（翻译官）
     ▼
HelloWorld.class（JVM 看的字节码，人打开是乱码）
     │  java 命令启动 JVM（厨师）
     ▼
程序运行，输出结果
```
- **JDK** = 工具箱（javac + JVM + 库都在里面）；跨平台靠"每个系统各自的 JVM + 统一的 .class"
- 固定咒语：`public static void main(String[] args)` = JVM 认的程序入口
- 命令行编译运行：`javac -encoding UTF-8 -d out src/HelloWorld.java` → `java -cp out HelloWorld`

## 三、变量与类型（第 1 课）

- **变量 = 贴了名字的盒子**；**类型**决定装什么、占多大、取值范围
- 常用四种：`int`（整数）`double`（小数）`boolean`（真假）`String`（文字，S 大写，比较用 equals）
- `=` 是"装进去"，不是"等于"；盒子只能装一个值，新值**覆盖**旧值
- 命名：小驼峰 `myScore`、见名知意、英文、不能数字开头/关键字；常量 `final` 全大写 `MAX_SCORE`
- 没赋值就使用 → **编译报错** `might not have been initialized`
- 类型转换：小→大**自动**（int→double）；大→小必须**强转** `(int)`，丢小数（175.9→175，截断不是四舍五入）
- **整数除法坑**：`9 / 5 = 1`（截断）；要 1.8 就写 `9.0 / 5`；装进 double 也救不了（先算完再装箱）

## 四、Scanner 输入（第 1 课）

- `nextLine()` 读一整行文字；`nextInt()` 读一个整数
- **坑**：`nextInt()` 把回车留在"管道"里 → 紧接的 `nextLine()` 读到**空字符串**
- **解法 1（推荐）**：统一用 `nextLine()` 读，再 `Integer.parseInt(文字)` 转数字
- **解法 2**：`nextInt()` 后补一句 `sc.nextLine();` 把回车吃掉
- `Integer.parseInt("18")` = 把文字翻译成数字；给它 `"abc"` 会报 NumberFormatException

## 五、判断分支（第 2 课，进行中）

- `if (条件) { } else if { } else { }`：**从上往下，命中一个就退出整条链**（所以"≥80"那档不用写 80~89）
- `if` 括号里必须是"真/假"；`if (score = 60)` 是错的（`=` 是赋值，`==` 才是比较）
- **文字比较**：`name.equals("吴政闻")` ✅ ｜ `name == "吴政闻"` ❌（== 比的是内存门牌号）
- `&&` 且：两个都真才真（登录校验用它）；`||` 或：一个真就真（用错会"密码错了也放行"）
- `!` 非：反过来

## 六、报错速认

| 报错 | 意思 |
|---|---|
| `';' expected` / 需要';' | 少分号 |
| `cannot find symbol` | 名字拼错 / 没 import / 类名文件名不一致 |
| `might not have been initialized` | 变量没赋值就用了 |
| `incompatible types: possible lossy conversion` | 大类型往小类型塞，要强转 |
| `ArrayIndexOutOfBounds`（以后会遇） | 数组下标越界 |
| 中文报"非法字符" | 用了全角标点（；"" （））——切英文输入法 |
