# 程序骨架模板（写新程序前先看一眼）

> 用法：新建类之后，**先把骨架敲出来，再想逻辑**。重复 10~20 次，就会变成本能。
> 忘了步骤时打开这个文件对照，不要凭感觉硬猜。

## 骨架 A：需要键盘输入的程序（最常用）

```java
import java.util.Scanner;                       // ① 顶部：借听写员（有输入就要它）

public class 类名 {                              // ② 类名必须和文件名一致！
    public static void main(String[] args) {     // ③ 大门（固定咒语）
        Scanner sc = new Scanner(System.in);     // ④ 造听写员 + 接上键盘
        System.out.print("请输入：");             // ⑤ 问话（别忘了分号）
        int num = sc.nextInt();                  // ⑥ 读一个整数
        // 或：int num = Integer.parseInt(sc.nextLine());   读文字再翻译成数字

        // ↓↓↓ 你的逻辑写在这中间 ↓↓↓

        System.out.println(num);                 // ⑦ 输出结果（别算完不打印）

        sc.close();                              // ⑧ 关掉听写员
    }                                            // ⑨ 大括号两两配对
}
```

## 骨架 B：不需要输入的程序（数据写死）

```java
public class 类名 {
    public static void main(String[] args) {
        int a = 10;                 // 数据直接写死，方便先调逻辑
        int b = 20;

        // ↓↓↓ 逻辑 ↓↓↓

        System.out.println(a + b);
    }
}
```

## 写完自查清单（5 条，逐条过一遍再运行）

1. **import 有没有**？（用了 Scanner 却没 import → 报 cannot find symbol）
2. **类名 = 文件名**？（不一致 → 报"类名应该是 xxx"）
3. **每句末尾有分号吗**？（漏了 → 报"需要';'"）
4. **大括号、小括号配对了吗**？（配对口诀：`{` 一多就补 `}`）
5. **输入用的类型对吗**？（`nextLine()` 给的是文字，要装进 int 必须先 `Integer.parseInt` 翻译）

## 高频报错 → 一秒定位

| 报错 | 原因 | 一句话修法 |
|---|---|---|
| `String 无法转换为 int` | 把 `nextLine()` 的文字塞进了 int 盒子 | 改用 `nextInt()` 或 `Integer.parseInt(...)` |
| `需要 ';'` | 上一行漏分号 | 看报错指的上一行行尾 |
| `cannot find symbol` | 名字拼错 / 没 import / 类名文件名不一致 | 逐个核对拼写 |
| `might not have been initialized` | 变量声明了没赋值就用 | 先赋值 |
| 输入后名字读到空 `[]` | `nextInt()` 后接了 `nextLine()` | 统一 `nextLine()` + `Integer.parseInt` |
| 红色 `equals` 找不到 | 对 boolean/int 用了 `.equals()` | 只有 String 用 equals；boolean 直接 `if (变量)` |

## 三句口诀（贴在屏幕上）

1. **有输入 → import + Scanner 四件套**（造 → 问 → 读 → 关）
2. **先搭骨架，再填逻辑**；骨架每次一模一样，逻辑每次不同
3. **写完过一遍自查 5 条**，再按运行
