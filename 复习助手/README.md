# Java 复习助手（本地知识库检索工具）

> 用途：把学过的知识点做成"可搜索"的库，忘了什么一搜就到，命中的关键词会**黄色高亮**。
> 完全离线、无需安装、双击即用。

## 怎么打开

三种方式任选：

1. 双击 `打开复习助手.bat`（推荐，自动用默认浏览器打开）
2. 直接双击 `index.html`
3. 桌面快捷方式（若已创建）"Java复习助手"

## 三个功能

| 标签页 | 作用 |
|---|---|
| 🔍 **搜索知识点** | 输入关键词（支持多关键词，用空格分隔），结果按相关度排序，命中词黄底高亮；上方标签可筛选阶段（P0 / P1-基础 / P1-判断 / 报错 / 工具 / 规划） |
| 🎲 **随机抽查** | 点一下随机抽一条知识点，先自己讲一遍，再点"显示答案"对答案 |
| 💬 **问答速查** | 写下你的疑问，工具从知识库找出最相关的 3 条答案；每次提问自动记录 |
| 📝 **我的提问记录** | 只属于你的提问历史（存在浏览器本地，**不进入聊天记录**），可复制/导出成 Markdown 存进笔记 |

## 小技巧

- 搜索框里按 **回车** 直接搜
- 关键词越具体越准：`equals`、`整数除法`、`nextInt`、`短路`、`break`、`报错`
- 想找"我踩过的坑"→ 搜 `报错`，或点标签 `报错`
- 想系统复查 → 先用 🎲 随机抽查连抽 5 条，讲不出来的就是薄弱点

## 知识库范围与更新

- 当前范围：**P0 ~ P1 第 2 课**，共 30 条
- 更新方式：老师每学完一个阶段就往 `index.html` 里的 `KB` 数组补条目（格式：id / tags / kw / title / body）
- 你也能自己加：复制一条现有条目，改内容即可（注意每条 `id` 不要重复）

## 说明

- 提问记录存在浏览器 localStorage 里：换浏览器/清缓存会丢，重要内容记得"导出为文件"
- 这个文件会跟着 `git push` 进 GitHub 仓库，换电脑 clone 下来就能用
