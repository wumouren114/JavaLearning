## 0. 先读这节：定位与心态（现实，但完全可行）

### 0.1 大一找实习的真实情况（先说清楚，避免走错路）
1. **大厂暑期实习基本不招大一**：头部大厂（阿里、腾讯、字节等）的暑期实习项目在官网就写明面向大三及以上（本质是次年校招的提前批）。双非大一进大厂暑期实习的概率趋近于零，每年个别案例属于幸存者偏差。**所以本规划不押注大厂**。
2. **中小公司/初创公司/本地企业完全有机会**：它们的招聘逻辑是"能干活、够踏实、可培养、薪资要求低"。暑期正是业务缺口期，一个带着**两个完整项目、基础能讲透、代码习惯好**的大一学生，完全能拿到 offer。很多这类公司面试只有 2 轮，难度可控。
3. **就算暑期没上岸也不亏**：按本路线执行后，你的实力会明显超过同届同学；大二暑假再冲一轮，胜算翻倍。**这条路投入的时间 100% 不浪费。**

### 0.2 面试官衡量你的三把尺子
| 尺子 | 含义 | 本路线的应对 |
|---|---|---|
| 基础 | Java 核心、集合、MySQL、框架原理能"讲"出来而非"背"出来 | 每阶段结束设**验收答辩** |
| 项目 | 是不是自己一行行写的、每个设计决策能否解释 | 两个亲手写的项目 + 部署上线可访问 |
| 潜力 | 算法题（笔试门槛）、学习能力、表达 | 全年贯穿刷题 + 每周输出笔记 |

### 0.3 预算与弹性（重要）
- 从现在（2026 年 9 月）到 2027 年 6 月中旬约 **40 周**：平时每周约 12~14h，寒假（约 6 周）若能加码到每天 4~5h，总预算约 **550~620 小时**。
- **寒假是大一最重要的窗口**（没有课业打断），务必把《寒假作战计划》当回事。
- 进度落后时按 **9 章"可裁剪清单"** 砍内容，核心三件套（JavaSE / MySQL / SpringBoot+项目）绝不砍。
- 期末考试周（约 4 周总量）自动降速为"保温模式"，别焦虑。

## 2. 分阶段详细目录（学习内容清单）

> 每个阶段结尾都有一行 **「过关标准」**，达标了才进入下一阶段——到时候我会抽问、让你讲代码、给你出机考题。

### P0 环境与工具链（约 8h）— 开学第 1~2 周
- [ ] 弄懂 Java 的"编译 + 运行"原理（.java → 编译器 → .class → JVM）
- [ ] 确认安装 **JDK 17 或 21（LTS）**，命令行能跑 `java -version`、`javac -version`
- [ ] 熟悉 IDEA 常用快捷键与调试（断点、Step Over）的打开方式
- [ ] 注册 GitHub，学会：clone / commit / push / 查看历史
- [ ] 了解 Markdown 语法（本文件就是 Markdown 写的）
- [ ] 选定笔记工具（语雀/飞书/掘金/本地 MD 均可），建好《Java 学习笔记》第一篇
- **过关标准**：能解释"从代码到屏幕上出结果"的全过程；今天写的代码今天推上 GitHub；一个报错能看懂大概意思。

### P1 Java SE 核心（上）：语法 → 面向对象（约 110h）— 9 月 ~ 11 月中
- [ ] 变量、8 种基本类型、类型转换、运算符
- [ ] Scanner 键盘输入；控制台程序套路
- [ ] 分支：if / else / switch
- [ ] 循环：for / while / do-while、break、continue、嵌套循环
- [ ] 数组：声明/遍历/复制、二维数组、Arrays 工具、增强 for
- [ ] 方法：定义、参数传递（值传递）、重载、递归入门
- [ ] **面向对象核心（本阶段重中之重）**：类与对象、构造器、this、封装（private + getter/setter）、static、包
- [ ] 继承 extends、super、方法重写、多态
- [ ] final、抽象类、接口（含默认方法）、Object 的 toString/equals/hashCode
- [ ] 综合练习：**学生信息管理系统 v1**（控制台 + 数组/ArrayList），先用"过程式"写一遍，再用面向对象重构一遍
- **过关标准**：不用查资料能写出"类 + 继承/接口 + 多态"的小程序；能口头讲清封装/继承/多态各解决什么问题；项目 v1 无报错跑通。
- **资源**：B 站搜索"黑马程序员 JavaSE 基础"或"韩顺平零基础学 Java"（选一个跟到底，别换）；配菜鸟教程 runoob.com 查语法；书可备《Java 核心技术 卷 I》当字典（不必从头读）。

### P2 Java SE 核心（下）：集合与进阶（约 80h）— 11 月中 ~ 1 月中
- [ ] String / StringBuilder / StringBuffer 区别与常用 API
- [ ] 包装类、自动装箱拆箱、Math / Random、日期时间（java.time 包）
- [ ] **集合框架（面试必考，认真学）**：List（ArrayList/LinkedList）、Set（HashSet/LinkedHashSet/TreeSet）、Map（HashMap/TreeMap）、遍历的几种写法、Collections 工具
- [ ] 泛型基础；Comparable / Comparator
- [ ] 异常体系：try-catch-finally、throws、自定义异常、常见运行时异常
- [ ] IO：File、字节/字符流、缓冲流、读写文本文件（用流把系统数据存进文件）
- [ ] 序列化概念（了解）
- [ ] 多线程入门：创建线程的两种方式、线程生命周期、synchronized 和线程安全的概念、线程池概念（了解层面，深挖放到面试期）
- [ ] Lambda 与 Stream 流入门（filter/map/collect）；Optional 了解
- [ ] **学生信息管理系统 v2**：集合存储 + 异常处理 + 读写文件，数据重启不丢
- **过关标准（M3 总验收）**：现场手写——单例模式、三种遍历 HashMap 的方式、字符串反转；口答——ArrayList vs LinkedList、== 与 equals、HashMap put 的简单流程、异常继承关系。
- **资源**：《Java 核心技术 卷 I》对应章节 + 视频课对应部分；面试考点可先看"黑马程序员集合源码"章节感受深度。

### P3 MySQL 数据库（约 50h）— 寒假前半
- [ ] 安装 MySQL 8 + 可视化工具（Navicat / DBeaver 二选一）
- [ ] 建库建表、主键/外键/约束、数据类型
- [ ] 增删改查；where / order by / limit
- [ ] 聚合函数、group by、having
- [ ] **多表查询**：内连接/左连接/右连接、子查询（面试笔试高频）
- [ ] 索引：是什么、怎么建、什么时候失效（概念层）
- [ ] 事务：ACID 特性、隔离级别概念、怎么开启事务
- [ ] 三大范式（概念了解）
- [ ] SQL 刷题 30~50 道（牛客网 SQL 题库 / LeetCode SQL 入门）
- **过关标准**：给场景手写 SQL（如"统计每个部门平均工资大于 5000 的部门"）；口答事务四大特性。
- **资源**：书《MySQL 必知必会》+ B 站任一配套视频；刷题站 nowcoder.com。

### P4 JDBC + 连接池（约 15h）— 寒假
- [ ] JDBC 六步流程、DriverManager / Connection / Statement
- [ ] PreparedStatement（为什么能防 SQL 注入）
- [ ] 事务控制、ResultSet 读取
- [ ] 连接池思想（Druid / HikariCP 用起来）
- [ ] **学生信息管理系统 v3**：数据真正存进 MySQL（脱离文件存储）
- **过关标准**：口答"JDBC 执行一条 SQL 的全过程"；说明 PreparedStatement 与 Statement 的区别。

### P5 前端入门——够用即可（约 10h）— 寒假
> 定位：后端同学需要"看得懂、能联调"，不深钻。
- [ ] HTML 常用标签、表单（能看懂页面结构）
- [ ] CSS 选择器与盒模型概念（能改个样式）
- [ ] JS 基础：变量/函数/DOM 简单操作/事件
- [ ] 了解 Ajax/fetch：前端怎么向后端发请求（概念 + 会抄着用即可）
- **过关标准**：能说出"浏览器输入网址回车后发生了什么"的粗略过程（后面 P6 会讲全）。
- **资源**：MDN（developer.mozilla.org）查文档，视频只看"前端三件套入门"精简版。

### P6 Java Web 基础：HTTP / Tomcat / Servlet（约 30h）— 寒假后半
- [ ] HTTP：请求/响应结构、常见状态码（200/302/400/401/404/500）、GET vs POST
- [ ] Tomcat 安装与启动，部署一个 war/项目
- [ ] Servlet：生命周期、request/response 常用 API
- [ ] 转发 vs 重定向；Cookie vs Session
- [ ] Filter 过滤器概念（登录校验场景）
- [ ] JSP 能看懂即可（知道它最终会被翻译成 Servlet）
- [ ] MVC 思想（Model-View-Controller）
- **过关标准**：口答一次完整 HTTP 请求从浏览器到 Servlet 又回来的链路；说出 Session 和 Cookie 的区别。
- **资源**：B 站"黑马程序员 JavaWeb"教程（Servlet 部分），跟练一个登录注册小案例。

### P7 Maven + Spring Boot + MyBatis（约 100h）— 大一下 3 月 ~ 4 月中（核心阶段）
- [ ] Maven：pom.xml、坐标、依赖管理、本地仓库、生命周期（会配阿里镜像）
- [ ] Spring 核心思想：**IoC 容器 / DI 依赖注入 / AOP 概念**（注解用法为主，原理讲到能答面试题）
- [ ] Spring Boot 起步：@SpringBootApplication、yml 配置文件、多环境配置
- [ ] 分层架构：controller / service / mapper / entity（dto）各层职责
- [ ] RESTful API 设计规范；用 Apifox / Postman 调试接口
- [ ] 参数校验 Validation、全局异常处理、拦截器
- [ ] Lombok 使用
- [ ] MyBatis：XML 与注解两种写法、动态 SQL、#{} 与 ${} 的区别
- [ ] MyBatis-Plus：内置 CRUD、分页插件、条件构造器
- [ ] 单元测试入门（JUnit，测一个 service 方法）
- [ ] 日志框架（slf4j + logback 会配置会用）
- **过关标准（M5）**：口答——IoC/DI 是什么、Spring Boot 为什么"启动即用"（自动配置概念）、MyBatis 和 JDBC 的关系；**白板写一个"创建用户"接口的完整链路（Controller→Service→Mapper→SQL）**。
- **资源**：B 站"尚硅谷 SpringBoot"（选 3.x 新版本课程）或"黑马程序员 SpringBoot + MyBatis-Plus 实战"；官方文档 spring.io/quickstart。

### P8 项目一：练手全栈 CRUD（约 25h）— 与 P7 后半并行（3 月 ~ 4 月中）
- **选题**：《图书管理系统》或《学生宿舍管理系统》
- **功能**：登录（会话方式）、增删改查、分页查询、简单统计
- **技术栈**：Spring Boot + MyBatis-Plus + MySQL + Thymeleaf 或最简单的前端页面
- **目的**：把 P3~P7 串成一条完整的"请求→服务→数据库"链路，踩一遍所有新手坑
- **产出**：GitHub 仓库、README、能本地跑通
- 不追求华丽，追求**完整**。

### P9 Redis + Linux 部署 + 项目二（主打，约 130h）— 4 月中 ~ 6 月中
- [ ] **Redis**（20h）：常用数据结构、过期时间、缓存三大问题（穿透/击穿/雪崩）概念、Spring Data Redis 用法
- [ ] **Linux 基础**（10h）：常用命令（cd/ls/mkdir/vi/ps/kill/日志查看）、权限概念
- [ ] **云服务器部署**（15h）：阿里云/腾讯云**学生认证服务器**（约 10 元/月）→ 装 JDK/MySQL/Redis → 项目打包 jar → Nginx 反向代理 → 线上可访问
- [ ] **项目二（主打项目，约 85h）**——《校园二手集市》或同类（论坛/博客社区）：
  - 用户注册登录：JWT + 拦截器鉴权（为什么不用 Session？要能讲）
  - 商品/帖子：发布（含图片上传）、编辑、上下架
  - 搜索 + 分页；评论；点赞/浏览量
  - **Redis 缓存热门商品/浏览量**（讲清缓存与一致性问题）
  - 管理员后台：封禁用户/删除违规内容（会用拦截器或简单角色控制）
  - 全局异常处理 + 参数校验 + 日志
  - 部署上线 + 写 README + 画系统架构图 + 整理接口文档
- **过关标准（M6）**：能对项目做 **30~40 分钟讲解**——为什么用 Redis、索引怎么建的、JWT 登录流程、上线踩过什么坑；每句话都经得起追问。
- **资源**：黑马"Redis 入门到实战"；菜鸟教程 Linux；部署搜"SpringBoot 项目部署云服务器教程"（选近期发布的新教程）。

### P10 简历 + 八股 + 投递冲刺（约 40h，5 月 ~ 6 月底，与 P9 并行）

## 3. 两条贯穿线（全年都要做）

### 3.1 算法刷题（每日 30~45 分钟）
- **为什么**：中小公司笔试/面试也会考简单~中等算法；大一的你算法题量是简历上除了项目以外最硬的证明（双非学生靠题量逆袭最常见）。
- **节奏**：平时工作日 1 题（不会就看题解、看懂后**必须自己敲一遍**），周末复盘本周错题。每周约 5 题，一年约 180~220 题。
- **顺序**（与校内数据结构课配合）：数组/字符串 → 双指针 → 栈与队列 → 哈希表 → 链表 → 二叉树 → 递归/回溯 → 排序与二分 → 动态规划入门
- **题源**：LeetCode 热题 HOT 100（leetcode.cn）→ 代码随想录（programmercarl.com，按它的目录刷）→ 牛客网剑指 Offer。
- **建议报名**：10~12 月学校若通知**蓝桥杯**报名（Java 组，次年 3~4 月省赛），报上！以赛促学，省奖是简历亮点。
- 做题时一律用 **Java** 写，和课程互相巩固。

### 3.2 笔记 / Git / 输出习惯
- 每天的学习产出：**代码（推到 GitHub）+ 笔记（自己的话写一遍）**，缺一即视为"没学"。
- 笔记记什么：当天知识点的"人话版解释" + 你踩的坑 + 一段示例代码。
- 每两周把一篇最有心得的内容发成博客（掘金/CSDN），面试时可以放链接——这是面试官能看到你"学习能力"的证据。

| 周日（2~3h） | 刷题 1~2 道 + 错题复盘 | + 30min 周小结发我打卡 |
| 每天 | 睡前 5 分钟 | 在打卡文件里登记一句话进度 |

**怎么跟我配合（全程机制）**
1. **每次学习结束**回来说一句话：`今天学了：___ / 产出：___ / 卡点：___`
2. **卡住超 2 天**必须来找我——问题会发酵，不允许囤积
3. 提问时带上：①你在做什么 ②**完整报错**或代码 ③你试过什么 ④要我做什么（讲概念/查 bug/出题）
4. **每阶段完成约验收**：我抽问概念 + 你讲你的代码 + 现场机考题，通过才进下一阶段
5. 你负责执行与反馈，我负责拆课、答疑、出练习、审代码、阶段验收、改简历、模拟面试
6. 进度落后不用慌，我们会按"可裁剪清单"一起调计划——**唯一不许砍的：动手写代码的习惯**

### 15 条军规（贴墙）
1. 视频只看不敲 = 白看；每讲必跟敲一遍
2. 先自己读报错 5 分钟，再求助
3. 一个 bug 卡 2 天必须上报
4. 每天必须有产出（代码或笔记），哪怕只有 20 行
5. 代码当天推 GitHub，不隔夜
6. 不囤问题、不跳过验收
7. 笔记用自己的话写，不抄视频文案
8. 不跟别人比进度，只跟上周的自己比
9. 不会的先查官方文档/菜鸟教程，再问 AI
10. 学新框架前先确认旧环节过关（顺序别乱）
11. 手机放另一个房间（学习时段）
12. 每周日晚 30 分钟周小结，雷打不动
13. 期末考试周自动切保温模式，别硬扛
14. 寒假是全年的胜负手，尽量每天 4~5h
15. 累了就休息一天，但第二天必须补打卡——放弃只发生在"连续断 3 天"

## 5. 投递指南（5~6 月开始看，详细版届时我给）

- **时间窗口**：日常实习全年都在招；大厂暑期实习 3~4 月开（投了当练手）；想 7 月入职的日常实习岗，**4~6 月**投最合适；本地小公司随时可聊，可接受"暑期全职/平时远程"。
- **渠道**：Boss 直聘（中小公司主力）→ 实习僧 → 牛客网讨论区/招聘 → 公司官网校招页 → **学长学姐内推（双非最有效的通路之一，大胆开口）**。
- **简历要点**：一页纸；技术栈放显眼处；两个项目各 3~4 行（技术栈 + 你的职责 + 难点/量化）；放 GitHub 与线上项目地址；**不写"精通"**。
- **面试常见流程**：自我介绍 → 项目深挖 → Java/数据库八股 → 手撕 1~2 道算法 → 反问。全程约 30~60 分钟。
- **心态**：被拒 20 次拿到 1 个 offer 是常态，把每次面试录音复盘；面试官对大一预期本来就不高，**自信 + 真诚 + 能干活**就是你的杀手锏。

## 附录 C：面试八股最终清单（6 月突击用，★=优先级）
