# 开学第一周行动卡（Day 1 ~ Day 7）

> 适用：军训收尾 / 开学第一周（每天能挤出 40~60 分钟即可）
> 第一周目标不是"学多少"，是**建立每天碰代码的习惯**，顺便把第 0 课收尾。
> 主教材：`01-JavaSE/第0课-P0-环境与工具.md`（下面只写"任务 N"就是指它的 7 个任务）

## 每日微任务（做完打勾 ✅）

### Day 1（约 45 分钟）—— 先搞清楚自己在干嘛
- [ ] 读《第0课》§1「三个必须搞懂的概念」，能对着图讲出 .java → javac → .class → JVM
- [ ] 打开终端跑三条体检命令：`java -version`、`javac -version`、`git --version`（都有输出就过关）
- [ ] 打开 `MyFirstProject/src/HelloWorld.java`，对照 §3 的注释逐词读一遍
- 完成度自评：今天只读不写也没关系，但**必须打开过 IDEA**

### Day 2（约 50 分钟）—— 第一次"改"代码
- [ ] 任务 2：把 HelloWorld 改成打印三行自我介绍，点绿三角运行
- [ ] 故意删掉一个分号 → 看报错长什么样 → 改回来（消除对报错的恐惧）
- [ ] 把自我介绍改成 4 行：加一行"我的偶像是 _"

### Day 3（约 60 分钟）—— 亲手指挥编译
- [ ] 任务 3：在 Terminal 里执行 `javac -encoding UTF-8 -d out src/HelloWorld.java` 和 `java -cp out HelloWorld`
- [ ] 去 `out` 目录亲手找到 `.class` 文件（摸一摸字节码）
- 中文乱码就敲 `chcp 65001` 再跑

### Day 4（约 60 分钟）—— 让程序跟你对话
- [ ] 任务 4：Scanner 打招呼程序跑通（输入名字 → 回应你）
- [ ] 自己加"你多大了？"功能并打印回应
- 这就是你人生第一个"输入→处理→输出"的完整程序，值得发一条朋友圈

### Day 5（约 45 分钟）—— 偷看程序走路
- [ ] 任务 5：断点调试五步走（F8 单步、看 Variables 面板、F9 继续）
- 如果时间紧，Day 5 可以和 Day 4 合并

### Day 6（约 60 分钟）—— 把代码送上云端（成就感最强的一天）
- [ ] 注册 GitHub（若还没有），记住用户名
- [ ] 依次执行任务 6 的 git 命令：config → init → add → status → commit
- [ ] GitHub 上建 `JavaLearning` 仓库 → remote add → push
- [ ] 刷新网页看到文件 = 🎉 你的作品集开张了
- 卡在密码验证就看讲义里"令牌（ghp_ 开头）"那段

### Day 7（约 40 分钟）—— 沉淀 + 汇报
- [ ] 任务 7：打开 `01-JavaSE/我的笔记/001-程序是怎么跑起来的.md`，用自己话填完
- [ ] 回来打卡：
  ```
  第0课完成 ✅
  产出：打招呼程序 + GitHub 仓库 + 笔记001
  卡点：___
  ```
- [ ] 第 0 课完成进度表同步更新（告诉我，我来帮你勾）

## 第一周三条红线
1. **每天至少打开一次 IDEA**——哪怕只写 3 行。习惯比速度重要。
2. 某天实在累（军训后遗症），可以只做 10 分钟或直接休息——**但第二天必须补上**。连续断 3 天 = 危险信号，我随时等你回来续上。
3. 卡住超过 2 天，把完整报错贴给我，不许自己硬扛。

## 完成后你将得到
- P0 验收（我出 3 个小问题 + 看你代码）
- 解锁 P1 第 1 课（讲义已备好：`01-JavaSE/第1课-P1-变量与基本类型.md`）
