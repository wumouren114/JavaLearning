## 一、概念问答（8 题，每题用 1~3 句话回答）

1. `javac` 和 `java` 分别是干什么的？`.class` 文件是什么？
2. 为什么同一个 `.class` 文件在 Windows、Mac、Linux 上都能运行？
3. 默写 main 方法那行"固定咒语"。
4. `import java.util.Scanner;` 这行是干嘛的？`System.in` 指的是什么？
5. `nextLine()` 和 `nextInt()` 分别读什么？
6. 报错 `cannot find symbol` 通常意味着什么？（不用精确术语，说你理解的）
7. 不借助 IDEA，在命令行把 `src/HelloWorld.java` 编译进 `out` 目录并运行，两条命令是什么？
8. `git commit` 和 `git push` 有什么区别？`git remote add origin ...` 是干嘛的？

## 答案与自查标准

- 第 1 题：javac = 编译器（.java → .class）；java = 启动 JVM 运行 .class。
- 第 2 题：每个平台各自装了对应版本的 JVM，.class 是 JVM 的通用语言。
- 第 3 题：`public static void main(String[] args)`。
- 第 4 题：import 引入 JDK 提供的工具类 Scanner（负责读键盘输入）；System.in = 键盘（标准输入）。
- 第 5 题：nextLine 读一整行文字（String）；nextInt 读一个整数。
- 第 6 题：用了没声明/没导入的名字——多半是拼写错误、少 import、类名不一致。
- 第 7 题：`javac -encoding UTF-8 -d out src/HelloWorld.java` 和 `java -cp out HelloWorld`。
- 第 8 题：commit 是在本地存档（生成版本号）；push 是把本地存档上传到 GitHub；remote add 是把"远程仓库地址"起个名（origin）登记到本地。

- B：输入两次文字后输出完整句子 = 通过（提示：每行输入之间别用 nextInt 混 nextLine）。
- C：能说出变量名和值（哪怕只答出 sc 和一个存名字的 String 变量）= 通过。
- Git 题：仓库 URL 能打开、文件都在 = 通过。
